How do I open this page on the server? (tunnel link, token)

The dashboard listens on 127.0.0.1:8080 only - by design, it is never exposed to the internet. From your laptop, open a tunnel and then use the local link:

ssh -N -L 8080:127.0.0.1:8080 ubuntu@<server-ip>
# then open:  http://127.0.0.1:8080/?token=<DASHBOARD_TOKEN>#pipeline

On the server, ops/dashboard_link.sh prints that exact command, the service state and the link (the token stays masked). The token lives in /etc/bestgaa/dashboard.env: sudo sed -n 's/^DASHBOARD_TOKEN=//p' /etc/bestgaa/dashboard.env. The ?token= form is stored in this tab and stripped from the address bar; without it, paste the token above.

Saved channel changes are not fully applied yet.

New channels activate on a running, upgraded bot after access checks. Existing edits/removals require an approved restart.

PIPELINE INTEGRITY · NOTHING DROPPED
Every post we took in — where did it go?







The one thing no single panel can prove: intake = posted + withheld + dropped (with a reason) + waiting + failed. Each post is read from the bot's own queue and delivery ledger and classified into exactly one of those states. A post with no send, no delivery row and no recorded reason is unaccounted — that is a possible lost deal or lost commission, and it turns this panel red instead of being averaged away. Every withheld or dropped post keeps its reason, every posted post shows when its first chunk actually left, and every configured source/channel that produced nothing is named.
