ROOT CAUSE 1 — CHANNEL MEDIA INVISIBLE (asalu bug)
--------------------------------------------------
Baileys 7.0.0-rc14 lo confirmed upstream bug.
Reference: WhiskeySockets/Baileys issue #2199, fix PR #2434 (inka merge avvaledu).

Verified inside the installed package:
  node_modules/baileys/lib/Utils/messages.js:99-105
      isNewsletter branch -> options.upload(...)
  node_modules/baileys/lib/Utils/messages-media.js:665
      const url = `https://${hostname}${MEDIA_PATH_MAP[mediaType]}/...`
  node_modules/baileys/lib/Defaults/index.js:84
      MEDIA_PATH_MAP = { image: '/mms/image', video: '/mms/video', ... }

Ante: Channel (newsletter) media kuda normal chat path `/mms/image` ki upload
avutundi. WhatsApp daaniki `/o1/...` directPath istundi. Channel renderer
`/o1/` ni accept cheyyadu -> stanza ki ack error 479 vastundi -> subscribers ki
photo kanipinchadu. Kaani `sendMessage()` success ga resolve avutundi, andhuke
log lo `"result":"sent","media":1` ani vachedi. Log correct, delivery kaadu.

Official WhatsApp Web client vaadedi:
  /newsletter/newsletter-image  +  ?server_thumb_gen=1   -> /m1/... directPath

FIX APPLIED (bridge.js) — node_modules ni touch cheyyaledu
  - NEWSLETTER_MEDIA_PATH_MAP: /newsletter/newsletter-{image,video,...}
  - newsletterUpload(): server_thumb_gen=1, video ki server_transcode=1,
    anni media hosts meeda failover.
  - sendNewsletterMedia(): prepareWAMessageMedia() ki custom upload isthundi,
    stale `url` field ni remove chestundi (official client laage directPath
    only), thumbnailDirectPath/thumbnailSha256 set chestundi, taruvata
    <message type="media"><plaintext mediatype="image"> stanza ni relay chestundi.
  - watchAck(): aa exact stanza id ki ack ni chustundi. Ack error vaste
    THROW avutundi. Ika "sent but invisible" jaragadu.
  - 3 media attempts fail aithe deal ni podam — cleaned source text + mana
    affiliate links tho text-only ga post avutundi (miss avvakudadhu).
  - Env kill switch: NEWSLETTER_MEDIA_FIX=false

ROOT CAUSE 2 — 2:09 AM TARVATA QUEUE AAGIPOVADAM
------------------------------------------------
Modati karanam: warm-up tier reset.
  warmupPolicy() lo day = (now - state.warmupStartedAt) / 1 day.
  bridge-state.json rebuild/reset aithe warmupStartedAt "ippudu" avutundi,
  ala day-1 tier ki padipotundi: hourCap 8, dayCap 18.
  Aa 18 posts aipoyaka rojanta silence. Idi exact ga "2:09 am post, tarvata
  emi ledu" symptom.
  FIX: WA_WARMUP_DONE=true (default) -> mature tier pin. Day 8+ tier ippudu
  hourCap 45, dayCap 700 (mundu 40/160).

Rendo karanam: nextAllowedAt future lo cake avvadam.
  Retry backoff + break gap + cap multiplier kalisi chala gantalu munduku
  vellochu, aa timestamp state file lo save avutundi.
  FIX: nextAllowedAt ki plausibility ceiling. Policy max + 5 min kanna ekkuva
  unte 60s hard floor ki reset, log:
    "implausible nextAllowedAt reset to hard floor"

Moodo karanam: silent hang.
  telegramFile() / sendMessage() / upload ekkada aina infinite ga vela dispatch
  loop apeyyachu — process alive, service "active", kaani em jaragadu.
  FIX: withTimeout() prati network step meeda; one dispatch ki 10 min hard
  ceiling; poller/worker/watchdog crash aithe 10s lo restart.

Nalgo karanam: dead socket.
  Baileys socket "open" ga undi ws chachipovachu, disconnect event raadu.
  FIX: connectionWatchdog() — deals ready unna 25 nimishalu em move avvakapote

     sentLastHour)
