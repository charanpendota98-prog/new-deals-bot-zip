  It imports bestgaa/main_bot_new.py and runs its real AffiliateClient -
  resolve -> convert -> shorten - so the answer is the posting code itself, not
  a second copy of the rules that can drift and then lie. Printed per link:

      source     : the URL you passed
      resolve    : the merchant page behind any source shortener
      posted as  : THE EXACT LINK THE CHANNEL WILL CARRY
      long link  : the destination behind it
      length     : short verdict, asked of the bot's own short domains/limit
      attribution: affExtParam2=5478322 -> https://www.flipkart.com/...
      verdict    : OURS / WRONG ACCOUNT / UNMONETIZED / transient (would retry)

  Blunt on purpose, because each failure needs a DIFFERENT fix:
    * OURS            the post pays 5478322. Nothing to do.
    * UNMONETIZED     the network has no campaign for that store/URL. The deal
                      still posts with a clean merchant link, but NOBODY IS
                      PAID. Fix: Affiliaters > Affiliate Settings > Networks +
                      Selections (connect EarnKaro, pick a network per store),
                      or take the deal from another source link.
    * NATIVE AMAZON-TAG FALLBACK
                      EarnKaro had no campaign for that Amazon URL, so the bot
                      posted its native ?tag= link. The bot's own gate refuses to
                      call that a conversion and so does this report: Associates
                      is still rejecting the account, so it earns NOTHING.
    * OURS (HYPD)     our HYPD creator-store link (store 93944, verified Meesho
                      only) - our commission link, Bitly-shortened when possible.
    * WRONG ACCOUNT   the returned link pays somebody else. Rotate the key and
                      check the selections; the bot's own gate refuses these.
    * would retry     the API was unreachable: the JOB retries, this is NOT a
                      deal that earns nothing (never conflate the two).
    * "NOT on a short domain" -> the shortener (Bitly, then is.gd) was
                      rate-limited/down, so the longer link posted instead:
                      a deal is never lost to a shortener outage.
